02 / ROLES

Who sees what.

Two roles for v1. Agent permissions are enforced server-side — even if someone tries to hack the URL, the backend refuses. The frontend just hides the menu items.

D
Admin · David
Owner / Full Access
  • ✓ See all leads across every agent (250+ contacts)
  • ✓ Reassign leads between agents (drag, click, bulk)
  • ✓ Bulk-import lead lists (CSV → GHL contacts)
  • ✓ View every agent's stats side by side (calls, talk time, conversion)
  • ✓ Pull reports — daily, weekly, by agent, by vertical
  • ✓ Listen to every call recording from any agent
  • ✓ Manage agent accounts (create, disable, reset password)
  • ✓ See JustCall billing, number health, spam flags
  • ✓ Revenue + pipeline forecasting
K
Agent · Khalid
Sales Agent
  • ✓ See only assigned leads (his queue)
  • ✓ Click-to-call straight from a lead row
  • ✓ Log call outcomes + add notes the team can see
  • ✓ Rotate his 3 phone numbers automatically
  • ✓ See own stats only (his calls, his demos)
  • ✓ See team feed of WINS only (demos + closes) for momentum
  • ✗ Cannot see other agents' lead lists
  • ✗ Cannot see admin reports, billing, or commissions
  • ✗ Cannot reassign leads or import contacts
SECURITY · 01
RBAC enforced server-side
Every API call checks the JWT token's role. Agent token requesting /api/admin/* → 403 Forbidden. Frontend hiding is cosmetic; backend is the wall.
UX · 02
Why "wins-only" team feed
Showing every no-answer demoralizes. Showing only demos booked + closes creates pressure without noise. Khalid sees Omar's win and calls harder.
SCALE · 03
Team Lead role comes later
Don't build a 3rd role until you have 5+ agents. When you do, add pod_id to JWT and filter — 30-min change.

06 / API

The endpoints to build.

10 endpoints. That's it. Each one is 10–20 lines wrapping a GHL or JustCall API call. Hand this list to Claude Code and start building.

POST
/api/auth/login
Username + password → returns JWT with role.
ROLE: PUBLIC · returns role=admin or role=agent
GET
/api/leads?assigned=me
Get leads for current user. Admin can pass ?assigned=agent1; agents always see only their own.
ROLE: BOTH · server-filtered
POST
/api/leads/:id/call
Triggers JustCall click-to-call. Returns call session ID. Backend rotates the agent's number.
ROLE: BOTH · agent's own leads only
POST
/api/leads/:id/note
Save note + outcome. Updates GHL contact, fires team feed event if win.
ROLE: BOTH · agent's own leads only
PUT
/api/leads/:id/assign
Reassign lead to a different agent. Updates GHL custom field.
ROLE: ADMIN ONLY · 403 if agent
POST
/api/leads/bulk-assign
Distribute N unassigned leads to an agent (with filter by tier/type).
ROLE: ADMIN ONLY
GET
/api/stats/agent/:id
Calls, talk time, demos, conversion. Agent can only request their own ID.
ROLE: BOTH · own only for agents
GET
/api/feed?type=wins
Team activity feed. ?type=wins for agent view, ?type=all for admin.
ROLE: BOTH · auto-filters by role
POST
/api/webhooks/justcall
JustCall fires this when a call ends. Updates GHL with duration, recording URL, outcome.
ROLE: WEBHOOK · signature verified
GET
/api/justcall/health
Number status (active / flagged / spam) + minutes used today.
ROLE: ADMIN ONLY
